# MCP-сервер открытых данных Йошкар-Олы

Репозиторий первого релиза MCP-сервера для открытых данных городского округа "Город Йошкар-Ола".



## Что это

MCP-сервер предоставляет внешним AI-инструментам структурированный доступ к утвержденным публичным данным администрации.

Текущий первый набор данных:

- муниципальные школы;
- муниципальные детские сады;
- дата последнего обновления сведений ФНС/ЕГРЮЛ.


## Публичный адрес MCP

Сервер доступен по адресу:

`https://apiiola.yasg.ru/mcp`

Transport: `streamable-http`.

## Источники данных

Данные собираются из публичных и утвержденных источников:

- публичный API ЦПР;
- ФНС России / ЕГРЮЛ;
- сведения об образовательных лицензиях;
- публичные контакты образовательных организаций.

## Какие поля возвращаются

Для школ и детских садов возвращаются только публичные поля:

- `display_order` - порядковый номер для отображения;
- `inn` - ИНН;
- `legal_address` - юридический адрес;
- `address` - фактический/публичный адрес;
- `phone` - телефон;
- `email` - электронная почта;
- `website` - официальный сайт;
- `fns_kpp` - КПП по данным ФНС;
- `fns_ogrn` - ОГРН по данным ФНС;
- `fns_full_name` - полное наименование по данным ФНС;
- `fns_short_name` - сокращенное наименование по данным ФНС;
- `fns_entity_type` - тип юрлица;
- `fns_registration_date` - дата регистрации юрлица;
- `fns_region_name` - регион по данным ФНС;
- `fns_status` - статус юрлица;
- `fns_address` - юридический адрес по данным ФНС;
- `fns_head_position` - должность руководителя по данным ФНС;
- `fns_head_name` - ФИО руководителя по данным ФНС;
- `license_number` - номер образовательной лицензии;
- `license_date` - дата лицензии/последнего изменения;
- `license_order` - приказ/основание лицензии;
- `license_term` - срок действия;
- `license_status` - статус лицензии;
- `license_issuing_organ` - орган, выдавший лицензию.

## Доступные MCP-инструменты

### `list_schools`

Возвращает список школ.

Параметры:

- `limit` - сколько записей вернуть, по умолчанию `100`, максимум `200`;
- `offset` - смещение, по умолчанию `0`.

Пример запроса пользователем:

```text
Покажи список муниципальных школ Йошкар-Олы.
```

### `search_schools`

Ищет школы по названию, ИНН, адресу, руководителю, email или сайту.

Параметры:

- `query` - строка поиска;
- `limit` - максимум результатов, по умолчанию `20`.

Примеры:

```text
Найди школу № 29.
```

```text
Какая школа находится на улице Петрова?
```

### `get_school_by_inn`

Возвращает одну школу по ИНН.

Параметры:

- `inn` - ИНН организации.

Пример:

```text
Покажи данные школы с ИНН 1215000000.
```

### `list_kindergartens`

Возвращает список детских садов.

Параметры:

- `limit` - сколько записей вернуть, по умолчанию `100`, максимум `200`;
- `offset` - смещение, по умолчанию `0`.

Пример:

```text
Покажи список детских садов Йошкар-Олы.
```

### `search_kindergartens`

Ищет детские сады по названию, ИНН, адресу, руководителю, email или сайту.

Параметры:

- `query` - строка поиска;
- `limit` - максимум результатов, по умолчанию `20`.

Примеры:

```text
Найди детский сад Пчёлка.
```

```text
Какие детские сады есть на бульваре Чавайна?
```

### `get_kindergarten_by_inn`

Возвращает один детский сад по ИНН.

Параметры:

- `inn` - ИНН организации.

### `get_data_update_info`

Возвращает дату последнего обновления данных ФНС/ЕГРЮЛ.

Пример:

```text
Когда последний раз обновлялись данные ФНС?
```

## Как подключить в MCP-клиенте

Если клиент поддерживает remote MCP / streamable HTTP, укажите:

```text
https://apiiola.yasg.ru/mcp
```

Если клиент просит тип транспорта:

```text
streamable-http
```

Авторизация на первом этапе не требуется, потому что сервер отдает только открытые публичные данные.

## Пример для локального тестирования

Установить зависимости:

```bash
python -m venv .venv
.venv/bin/pip install -e .
```

Запустить сервер:

```bash
MCP_HOST=127.0.0.1 MCP_PORT=8001 MCP_PATH=/mcp .venv/bin/yoshkar-ola-public-mcp
```

На Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\pip.exe install -e .
$env:MCP_HOST = "127.0.0.1"
$env:MCP_PORT = "8001"
$env:MCP_PATH = "/mcp"
.\.venv\Scripts\yoshkar-ola-public-mcp.exe
```

## Переменные окружения

- `CPR_PUBLIC_API_BASE_URL` - базовый URL публичного API, по умолчанию `https://apiiola.yasg.ru/api/v1`;
- `CPR_PUBLIC_API_TIMEOUT` - timeout HTTP-запросов к API в секундах, по умолчанию `20`;
- `CPR_PUBLIC_API_CACHE_TTL` - TTL кэша в секундах, по умолчанию `300`;
- `MCP_HOST` - host MCP-сервера, по умолчанию `127.0.0.1`;
- `MCP_PORT` - port MCP-сервера, по умолчанию `8001`;
- `MCP_PATH` - путь MCP endpoint, по умолчанию `/mcp`.

## Безопасность

Сервер построен так, чтобы минимизировать риск раскрытия данных:

- нет прямого подключения к боевой базе данных;
- нет доступа к исходным схемам ЦПР;
- нет SQL-запросов от пользователя;
- наружу возвращаются только заранее перечисленные публичные поля;
- сервер читает только публичный API;
- кэш короткий и не содержит служебных секретов.

## Деплой

Боевой деплой выполняется на VPS публичного API.

Ожидаемая схема:

```text
nginx 443
  /api/v1/* -> CPR Public API на 127.0.0.1:8000
  /mcp      -> Yoshkar-Ola Public MCP на 127.0.0.1:8001
```

systemd-сервис:

`yoshkar-ola-public-mcp.service`

Рабочая директория:

`/opt/yoshkar-ola-public-mcp`
